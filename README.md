# End-to-End E-Commerce Data Analytics Project (Python + SQL)
This project demonstrates an end-to-end data analytics pipeline using Python, MySQL, and SQL analytics queries on an e-commerce dataset.

## The workflow covers:

1) Importing multiple CSV datasets into MySQL using Python

2) Cleaning and transforming data

3) Performing descriptive, aggregation, window function, and analytical SQL queries

4) Extracting insights related to customers, orders, products, payments, and sellers

5) This project is designed to showcase real-world data analytics skills combining SQL + Python.

## Tech Stack:

1) Python 

2) MySQL 

3) Pandas 

4) MySQL Connector 

## Project Workflow:

### 1️⃣ Data Ingestion (CSV → MySQL)

Automatically reads multiple CSV files

Dynamically detects data types

Creates SQL tables programmatically

Inserts cleaned data into MySQL

### 2️⃣ Data Cleaning

Handles missing values (NaN → NULL)

Standardizes column names

Ensures SQL-compatible schema

### 3️⃣ SQL Analytics & Business Queries

A series of real-world analytical questions are answered using SQL:

List all unique customer cities

Count total orders placed in 2017

Calculate total sales per product category

Percentage of orders paid via installments

Customers count by state

Monthly order trends for 2018

Average products per order (city-wise)

Revenue contribution by each category (%)

Relationship between product price & purchase frequency

Seller revenue ranking using window functions

Moving average of order values per customer

Cumulative monthly sales across years

## Advanced SQL Concepts Used:

1) JOIN (INNER JOIN)

2) GROUP BY & Aggregations

3) WITH (CTE – Common Table Expressions)

4) Window Functions:

  DENSE_RANK()

  AVG() OVER()

  SUM() OVER()

5) Date functions (YEAR(), MONTH(), MONTHNAME())
